# ATHER | أثَر — نموذج تخيلي للنظام

منصة ذكاء اصطناعي لفحص الأدلة الرقمية (صور، صوت، فيديو) القادمة عبر منصات المراسلة، مع دمج مُعايَر للأدلة وقدرة على الامتناع («غير حاسم») بدل الحكم الخاطئ الواثق، وسلسلة حيازة مربوطة بالبصمات.

> **تنبيه:** هذا الموقع نموذج تخيلي لشكل النظام بعد اكتماله. كل الأسماء والأرقام والنتائج **بيانات توضيحية** ولا تمثل قضايا حقيقية.

## الصفحات
| الصفحة | الوصف |
|---|---|
| `index.html` | لوحة التحكم والقضايا |
| `intake.html` | استلام دليل — يحسب SHA-256 حقيقي بالمتصفح (الملف ما يطلع من الجهاز) |
| `analysis.html` | التحليل: صورة / صوت / فيديو |
| `report.html` | التقرير الجنائي والمراجعة الثنائية والختم |
| `custody.html` | سجل التدقيق — سلسلة بصمات حقيقية مع تجربة كسرها |

## النشر على GitHub Pages
1. سوّي مستودع جديد (مثلًا `ather-demo`).
2. ارفعي كل محتويات هذا المجلد للجذر (`index.html` لازم يكون بالجذر).
3. Settings ← Pages ← Source: **Deploy from a branch** ← الفرع `main` والمجلد `/ (root)` ← Save.
4. بعد دقيقة يطلع الرابط: `https://<اسم-المستخدم>.github.io/ather-demo/`

ما يحتاج أي بناء أو مكتبات — ملفات HTML/CSS/JS ثابتة.
